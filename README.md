# 🎬 AI Movie Recommendation System
An AI-powered Movie Recommendation System built with Flask and Machine Learning.
## Features
- AI-based Movie Recommendation
- TF-IDF + Cosine Similarity
- Fuzzy Search
- OMDb API Integration
- Movie Posters
- IMDb Ratings
- Responsive UI
- Bootstrap 5
- Flask Backend
## Technologies Used
- Python
- Flask
- Pandas
- Scikit-learn
- RapidFuzz
- HTML
- CSS
- JavaScript
- Bootstrap 5
- OMDb API
## Dataset
IMDb Top 1000 Movies Dataset
source: kaggle
